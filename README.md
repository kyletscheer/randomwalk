# Random Walk Laboratory

An interactive visualization of how random steps create patterns. Choose 4, 8, or 16/36 evenly spaced directions, or let each step choose a continuous random angle. Compare endpoint distributions under different movement rules.

## Run it

Open `index.html` in a modern browser. It is self-contained; no build step or server is needed. The page uses Google Fonts when online and falls back to system fonts otherwise.

## Explore

- Choose the number of directions, walks, steps, and animation pace.
- Switch between one walk and many; zoom with the wheel and pan by dragging.
- Try unrestricted headings, a minimum angle from reversing, or avoiding previously visited points within a chosen radius.
- Inspect displacement histograms, the endpoint cloud, distance, and endpoint statistics.

Inspired by [The Pudding’s “Pi”](https://pudding.cool/2026/11/pi/). Learn more about [random walks at MIT](https://www.mit.edu/~kardar/teaching/projects/chemotaxis(AndreaSchmidt)/random.htm) and on [Wikipedia](https://en.wikipedia.org/wiki/Random_walk).
